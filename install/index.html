Download SehgalMaruti.apk
  1. Tap the red button. The file SehgalMaruti.apk downloads.
  2. Open it from the notification (or Files → Downloads).
  3. If the phone says "not allowed", tap Settings → turn on "Allow from this source" → go back.
  4. Tap Install, then Open. Log in with your Employee No. and password.
  5. If "Play Protect" warns about an unknown app: tap More details → Install anyway. The app is from Sehgal Autoriders, not the Play Store.

This is a demonstration build signed with the Android debug key. A signed release build replaces it before staff roll-out. Not yet checked on a real phone - see the report.

Windows WEB APP

No Windows installer exists yet. Use the web app in Edge or Chrome; it works the same.

Open the web app
  1. Open the link above in Edge or Chrome.
  2. Click the install icon in the address bar (or menu → Apps → Install Sehgal Maruti) to get a desktop icon.
  3. Log in with your Employee No. and password.

iPhone WEB APP

There is no App Store or TestFlight app. This is the website added to the Home Screen, not a native iPhone app. Background microphone and location do not work this way.

Open on the iPhone
  1. Open the link above in Safari.
  2. Tap Share (square with an arrow) → "Add to Home Screen" → Add.
  3. Always open Sehgal Maruti from that icon, not from the browser, so you stay logged in.
